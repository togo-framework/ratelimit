# ratelimit — docs

The `togo-framework/ratelimit` plugin rate-limits requests with a token-bucket
limiter, as HTTP middleware or a direct `Allow` check.

- **Install:** `togo install togo-framework/ratelimit`
- **Marketplace:** https://to-go.dev/plugins/ratelimit
- **Source:** https://github.com/togo-framework/ratelimit

See [usage.md](usage.md).
